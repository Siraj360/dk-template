  1. Run it: npm install then npm start.
  2. Change the name: the brand option in src/app/app.config.ts.
  3. Edit the menu: public/menu.json (text, icon, route, children).
  4. Add a page: a component in src/app/pages, a route in app.routes.ts, a line in the menu.
  5. Publish it: npm run build and upload the dist folder, or push to GitHub (see the box below).
